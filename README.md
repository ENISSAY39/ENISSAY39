### 🌊 S.E.B.A.S.T.I.A.N. — maintenance prédictive · *en cours*

*Subsea Error Behavior Analysis & System Tracking Intelligent Analytic Network.* Semester Project EPF mené pour un client industriel de la robotique subaquatique. Objectif : greffer une couche de machine learning sur leur outil interne de visualisation des données d'exploitation, pour anticiper les défaillances des robots et réduire les interventions correctives non planifiées.

**Périmètre :** cadrage du cas d'usage · pipeline de nettoyage et jeu d'apprentissage documenté · POC de modèle avec métriques et limites · intégration dans l'interface web existante.

**Stack :** Python · Keras · pandas · Agile (sprints bimensuels)

> 🔐 Projet client — code non public.

### 🔒 OcéEns II — *repo privé*

Plateforme d'évaluation des enseignements de l'EPF, sur laquelle j'ai effectué mon stage de 4e année (juin – juillet 2026) pour la faire passer d'application fonctionnelle à outil exploitable en production. Multi-rôles avec périmètres par filière et campus, authentification Microsoft Entra ID (OAuth 2.0 / MSAL), dashboards par rôle, score de satisfaction et NPS, analytique par enseignant, export CSV.

Synthèses de verbatims via LLM avec une couche multi-fournisseur (Ollama, API compatibles OpenAI, Anthropic) administrable sans code, clés d'API hors base et suivi du coût réel à partir des compteurs de jetons.

**Stack :** FastAPI · SQLite/SQLModel · Jinja2 · Microsoft Graph · Docker

> 🔐 Le dépôt est **privé** (école) — mais l'activité est visible :
> jetez un œil aux [**contributions**](https://github.com/ENISSAY39) (~160 commits, ~30 PR).
